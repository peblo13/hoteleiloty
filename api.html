API Dokumentacja

Integruj wyszukiwanie lotów i hoteli z twoją aplikacją. RESTful API z pełną dokumentacją.

🔌 Wstęp

API HoteleILoty.pl pozwala deweloperom zintegrować wyszukiwanie lotów, hoteli i rezerwacje w swoich aplikacjach.

🔑 Autentykacja

Dla dostępu do API potrzebujesz API key. Skontaktuj się z nami aby go otrzymać.

curl -H "Authorization: Bearer YOUR_API_KEY" https://api.hoteleiloty.pl/v1/flights

📚 Endpointy

Loty: GET /v1/flights - wyszukiwanie lotów

Hotele: GET /v1/hotels - wyszukiwanie hoteli

Rezerwacje: POST /v1/bookings - twotz rezerwacji

📞 Wsparcie

Email: api@hoteleiloty.pl

Pełna dokumentacja: docs.hoteleiloty.pl
