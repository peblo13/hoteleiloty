# PUSH NA GITHUB - INSTRUKCJA MANUALNA

## Jeśli nie masz dostępu do terminal w v0, wykonaj to lokalnie:

### 1. Na swoim komputerze - Otwórz Terminal/Command Prompt

### 2. Przejdź do folderu projektu:
```bash
cd path/do/twojego/hoteleiloty
```

### 3. Skopiuj i wklej te komendy po kolei:

```bash
# Sprawdź status
git status

# Dodaj wszystkie zmiany
git add .

# Commituj zmiany
git commit -m "Improved website design for Google AdSense - Added premium UI, content, SEO optimization, and AdSense slots (7410885727, 9901317699)"

# Wypchnij na GitHub
git push origin website-improvement-for-adsense
```

## 4. Po push'aniu na GitHub:

1. Idź do: https://github.com/peblo13/hoteleiloty
2. Kliknij: **"Compare & pull request"** (powinno się pojawić)
3. Sprawdź zmiany
4. Kliknij: **"Create Pull Request"**
5. Dodaj opis: `"Google AdSense optimization - Premium design, SEO improvements, and ad integration"`
6. Kliknij: **"Create Pull Request"**

## 5. Merge do main:

1. Kliknij: **"Merge pull request"**
2. Potwierdź
